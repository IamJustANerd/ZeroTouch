# AGENTS.md - Your Workspace

## Core Rules
- Read `SOUL.md` and `USER.md` at session start
- Don't run destructive commands without asking
- Write things to files — mental notes don't survive session restarts

## Memory
- Daily notes: `memory/YYYY-MM-DD.md`
- Long-term: `MEMORY.md` (main session only)

## Group Chats
- Respond only when directly mentioned or when you can add genuine value
- Stay silent (HEARTBEAT_OK) for casual banter between humans

## Heartbeats
When you receive a heartbeat poll, read `HEARTBEAT.md` and follow it. If nothing needs attention, reply `HEARTBEAT_OK`.

## Tools
Skills provide your tools. Check `SKILL.md` for each skill. Keep local notes in `TOOLS.md`.
